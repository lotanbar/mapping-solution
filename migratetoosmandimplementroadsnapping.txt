=== THE PROBLEM ===

The app records GPS routes and snaps points to roads for a clean track.
The current road snapper (RoadSnapper.kt) uses MapLibre's queryRenderedFeatures().
This is a UI rendering API — it only works when the map is on screen.
Screen off = no rendering = no snapping = raw noisy GPS in the track.
This is the root cause of remaining noise in recordings.

Additionally, MapTiler vector/hybrid tiles filter out many minor roads,
so the user sees less road detail than OSM actually contains.


=== CURRENT ARCHITECTURE ===

- MapTiler vector/hybrid tiles   → visual map (roads, labels, satellite)
- queryRenderedFeatures()        → road snapping (broken: screen-off = fails)


=== NEW ARCHITECTURE ===

Two fully independent fetch pipelines:

1. OSM Overpass Pipeline (always running)
   - Fetches raw road geometry for the current area (bounding box)
   - Re-fetches as user location changes
   - Cached in memory (OsmRoadCache)
   - When screen ON:  roads and name labels are rendered as a GeoJSON layer on the map
   - When screen OFF: same cache, same code path — just no rendering needed
   - Used for ALL snapping decisions, always

2. MapTiler Pipeline (screen ON only)
   - Fetches raster satellite tiles for the current area
   - Rendered as the base background layer
   - Re-fetches as user pans/zooms
   - Not used when screen is off — raster imagery is not needed

queryRenderedFeatures → RETIRED completely.
MapTiler vector/hybrid tiles → RETIRED completely. Raster only.
OSM is the sole source of road data for both display and snapping.
